# 📊 Week 2: Titanic Exploratory Data Analysis (EDA)

> **Objective:** Dive deep into the cleaned Titanic dataset to uncover patterns, trends, and correlations through Exploratory Data Analysis.

Welcome to the Week 2 content for the **DevSyn Data Analyst Internship**! This week shifts focus from data preparation to visual storytelling and statistical exploration.

---

## 🗂️ Directory Structure

The files are meticulously organized to separate data, code, reports, and visual outputs:

* 📁 **`data/`** — *Contains the datasets used during this week.*
  * 📄 `Cleaned_Titanic.csv`: The cleaned version of the Titanic dataset from Week 1.
  * 📄 `titanic.csv`: The original raw dataset file.
* 📁 **`notebooks/`** — *Contains the Jupyter notebooks for analysis.*
  * 📓 `Titanic_EDA.ipynb`: The main notebook containing the Python code, visualizations, and insights derived from the dataset.
* 📁 **`reports/`** — *Contains documents and summaries related to the analysis.*
  * 📝 `Titanic_EDA_Report.pdf`: A comprehensive report detailing the exploratory analysis, findings, and visualizations.
* 🖼️ **`Visualizations/`** — *Contains high-quality exported charts and graphs generated during the EDA phase.*
  * `dashboard.png`
  * `q1_survival_pie.png`
  * `q2_gender_survival.png`
  * `q3_class_survival.png`
  * `q4_age_survival.png`
  * `q5_fare_survival.png`
  * `q6_alone_survival.png`
  * `q7_embark_survival.png`
  * `q8_class_fare.png`
  * `q9_correlation_heatmap.png`
  * `q10_familysize_survival.png`

## 🚀 Getting Started

To review this week's work:

1. **Explore the Code:** Open `notebooks/Titanic_EDA.ipynb` in Jupyter Notebook, JupyterLab, or VS Code to see the code execution and inline visualizations.
2. **Read the Report:** Review `reports/Titanic_EDA_Report.pdf` for a detailed, executive summary of the insights uncovered during the analysis.
3. **View the Charts:** Browse the `Visualizations/` folder for standalone, high-quality images of every chart produced during the analysis.

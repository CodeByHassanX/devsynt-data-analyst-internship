# Week 1: Titanic Data Preparation and Cleaning

Welcome to the Week 1 content for the Data Analyst Internship! This week focuses on the foundational steps of data analysis: data preparation and cleaning, using the classic Titanic dataset.

## Directory Structure

The files have been organized into the following directories for better structure and clarity:

* **`data/`**: Contains the datasets used and generated during this week.
  * `cleaned_titanic.csv`: The cleaned version of the Titanic dataset.
  * `cleaned_titanic (1).csv`: An additional copy/version of the cleaned dataset.
* **`notebooks/`**: Contains the Jupyter notebooks for data processing.
  * `Titanic_Data_Cleaning.ipynb`: The main notebook containing all the Python code, logic, and steps used to clean and prepare the raw Titanic dataset.
* **`reports/`**: Contains documents and summaries related to the analysis.
  * `Titanic_Project_Summary.docx`: A summary document detailing the project's objectives, steps taken during cleaning, and initial findings.

## Getting Started

To review this week's work:
1. Open the `notebooks/Titanic_Data_Cleaning.ipynb` file in Jupyter Notebook, JupyterLab, or VS Code.
2. The notebook will guide you through the process of handling missing values, encoding categorical variables, and preparing the dataset for further analysis.
3. Review the `reports/Titanic_Project_Summary.docx` for a high-level overview of the week's accomplishments and findings.

## Prerequisites
- Python 3.x
- Jupyter Notebook / JupyterLab
- Pandas, NumPy (and any other libraries used in the notebook)

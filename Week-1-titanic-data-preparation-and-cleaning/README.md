# 🚢 Week 1: Titanic Data Preparation and Cleaning

> **Objective:** Master the foundational steps of data analysis by preparing and cleaning the classic Titanic dataset.

Welcome to the Week 1 content for the **DevSyn Data Analyst Internship**! This week focuses heavily on transforming raw, messy data into a clean, analysis-ready format.

---

## 🗂️ Directory Structure

The files have been organized into the following directories for better structure and clarity:

* 📁 **`data/`** — *Contains the datasets used and generated during this week.*
  * 📄 `cleaned_titanic.csv`: The primary cleaned version of the Titanic dataset.
  * 📄 `cleaned_titanic (1).csv`: An additional copy/version of the cleaned dataset.
* 📁 **`notebooks/`** — *Contains the Jupyter notebooks for data processing.*
  * 📓 `Titanic_Data_Cleaning.ipynb`: The main notebook containing all the Python code, logic, and steps used to clean and prepare the raw Titanic dataset.
* 📁 **`reports/`** — *Contains documents and summaries related to the analysis.*
  * 📝 `Titanic_Project_Summary.docx`: A summary document detailing the project's objectives, steps taken during cleaning, and initial findings.

---

## 🚀 Getting Started

To review this week's work:

1. **Open the Notebook:** Launch `notebooks/Titanic_Data_Cleaning.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
2. **Follow the Code:** The notebook will guide you through the step-by-step process of handling missing values, encoding categorical variables, and formatting the dataset for further analysis.
3. **Read the Summary:** Review `reports/Titanic_Project_Summary.docx` for a high-level overview of the week's accomplishments and findings.
